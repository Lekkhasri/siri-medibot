**Siri MediBot** is an intelligent healthcare assistant designed to provide personalized medical support and advice. It leverages AI principles to answer health-related queries, recommend medications or remedies, and offer first-aid tips. The bot aims to bridge the gap between patients and healthcare by ensuring quick and accessible medical information.

🌐 **Live Demo**: [Visit Siri MediBot](https://sirimedibot.netlify.app/)

## Features  
- 🩺 **Health Query Resolution**: Instant answers to common health-related questions.  
- 💊 **Remedy Recommendations**: Provides basic medications and home remedies.  
- 🚑 **First-Aid Tips**: Offers guidance on managing minor injuries and emergencies.  

---

## Technologies Used  
- **Frontend**: HTML, CSS  
- **Interactivity**: JavaScript  

---

## Project Structure  
- `index.html` – Main structure of the bot.  
- `style.css` – Styling for an intuitive and clean interface.  
- `script.js` – JavaScript functionality for user interaction and logic.  

---
## Usage  

1. Launch the application by opening `index.html`.  
2. Interact with the bot to get medical tips, remedies, and first-aid guidance.  
3. Use it as a virtual assistant for quick healthcare-related queries.
